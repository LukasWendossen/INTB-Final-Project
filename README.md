## How to edit

- Your words go inside the `<p>` ... `</p>` tags (paragraphs). Each `<h2>` is a heading.
- Boxes marked **DRAFT** are writing prompts. Replace each one with your own paragraphs, then delete the box: everything from `<div class="draft">` to its closing `</div>`.
- To change a color for the whole site, edit the values under `:root` at the top of `assets/style.css`.
- To add a screenshot, put the image in `assets/` and add `<img src="assets/your-file.png" alt="what it shows">`.
